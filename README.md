# Java Development Internship Projects

## Overview

This repository contains Java projects developed as part of my Java Development Internship. These projects demonstrate fundamental programming concepts such as object-oriented programming, loops, conditional statements, arrays, methods, classes, user input handling, and problem-solving skills.

## Projects Included

### 1. Number Guessing Game

A console-based interactive game where the user attempts to guess a randomly generated number within a limited number of attempts.

#### Features

* Random number generation
* Maximum 10 guessing attempts
* High / Low hints after each guess
* Score calculation based on attempts
* Multiple game rounds
* Win/Lose result display
* User-friendly console interface

#### Concepts Used

* Java Random Class
* Loops
* Conditional Statements
* Methods
* User Input Handling

---

### 2. Student Grade Calculator

A console-based application that calculates student grades based on marks entered for multiple subjects.

#### Features

* Student name and ID management
* Multiple subject mark entry
* Total mark calculation
* Average mark calculation
* Overall grade calculation
* Subject-wise grade display
* Full report generation
* Menu-driven system

#### Concepts Used

* Arrays
* Methods
* Loops
* Conditional Statements
* Functions
* Data Processing

---

### 3. ATM Interface

A console-based ATM simulation system that performs basic banking operations.

#### Features

* Account creation
* PIN verification
* Secure login system
* Balance inquiry
* Deposit money
* Withdraw money
* Mini statement generation
* Transaction history tracking
* User-friendly menu system

#### Concepts Used

* Object-Oriented Programming (OOP)
* Classes and Objects
* Arrays
* Methods
* Loops
* Switch Case
* Conditional Statements
